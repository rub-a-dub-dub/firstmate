Armed merge poll across a macOS reboot (device renumbering), driven end to end
through the real operator entry points: bin/fm-pr-check.sh arms the poll, the
registration's recorded device component is then rewritten to a different
number (exactly what a reboot leaves behind: same inode, same bytes, new
device), and bin/fm-watch.sh runs its next poll against a PR that has merged
upstream. Only the recorded device number is changed; no live file is touched.

################################################################
# BEFORE  (base 7ce3cda - bin/fm-pr-lib.sh, bin/fm-watch.sh)
################################################################
$ bin/fm-pr-check.sh task-a https://github.com/o/r/pull/1
  armed: state/task-a.check.sh

    sidecar      16777230:524922159
