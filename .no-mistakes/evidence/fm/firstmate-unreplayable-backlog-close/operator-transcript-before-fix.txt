
========================================================
SCENARIO A - teardown for a task whose backlog row closed and then aged out of done_keep retention
========================================================

$ tasks-axi done demo-shipped-then-aged-out   # the row is closed normally

$ tasks-axi prune --keep 0 --state done   # retention archives the row out of the backlog

$ tasks-axi show demo-shipped-then-aged-out
code: NOT_FOUND (row_state is now '')

$ bin/fm-teardown.sh demo-shipped-then-aged-out
error: demo-shipped-then-aged-out's endpoint and local copy are cleaned up, but its backlog item could not be closed atomically (error: "Task \"demo-shipped-then-aged-out\" not found in this backlog"); the pending close is recorded and the next session start retries it

[exit status] 1

$ ls home/state/   # is a pending-close record left behind?
demo-shipped-then-aged-out.backlog-close  <-- a pending close that can never land

========================================================
SCENARIO B - the next session start, with that pending close on disk
========================================================

$ bin/fm-bootstrap.sh   # what does the operator see about the pending close?
(bootstrap said nothing about demo-shipped-then-aged-out)

$ ls home/state/   # did session start retire the record?
(retired: no demo-shipped-then-aged-out.backlog-close record)

========================================================
SCENARIO C - same archived row, but the teardown was killed mid-cleanup
========================================================

$ bin/fm-teardown.sh demo-interrupted-then-aged-out   # killed during destructive cleanup
[exit status] 143

$ bin/fm-bootstrap.sh   # next session start
(bootstrap said nothing about demo-interrupted-then-aged-out)

$ ls home/state/
(retired: no demo-interrupted-then-aged-out.backlog-close record)
